# Weather App 🌦️

A simple and intuitive Weather App that provides real-time weather updates for various locations. Built using **HTML**, **CSS**, **JavaScript**, and a **Weather API**, it offers users a clean and interactive interface to check weather conditions, including temperature, humidity, and forecasts.

## Features ✨

- 🌍 Search for weather updates by city name.
- 🌡️ Displays real-time temperature in Celsius or Fahrenheit.
- 💧 Shows additional details like humidity and weather conditions.
- 🖼️ User-friendly design with responsive UI.
- 🔄 Refresh button for live weather updates.

## Usage 🔧

1. Enter the name of the city in the search bar.
2. Press the "Search" button to fetch and display the current weather details.
3. Click the refresh icon to get the latest data.

## API Integration 🌐

This app uses the [OpenWeatherMap API](https://openweathermap.org/api) to fetch weather data. You can replace the API key in the JavaScript file to use your own key for extended usage.
